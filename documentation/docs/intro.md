# Strudel Node Editor

A Vue 3 component that puts the [Strudel](https://strudel.cc) live-coding editor in your own
app: a code editor, a node editor for instruments and effects, a timeline, transcription and
WAV or MIDI export. It is the same editor that runs at
[strudel.cnotv.xyz](https://strudel.cnotv.xyz).

- [Embed the editor](./guides/embedding-the-strudel-editor.md) in another repository.
- Read the source on [GitHub](https://github.com/cnotv/strudel-node-editor).
